# Решение 2

* В файле count-vm.tf настроил создание двух идентичных веб-серверов. Им назначилась созданная  группа безопасности.
* В файле for_each-vm.tf объявлена переменная, содержащая параметры для баз данных. С помощью for_each создались две разные конфигурации ВМ, main 2 vCPU, 4 RAM и replica 2 vCPU, 2 RAM.
* Для ресурса yandex_compute_instance.web добавлен блок depends_on = [yandex_compute_instance.db]. Что веб-серверы создавались после успешного развёртывания баз данных.
* Публичный SSH-ключ передан с локальной машины  file("~/.ssh/id_rsa.pub") в блоке locals и скопирован во все ВМ через metadata.

# Решение 4

* Сделал шаблон hosts.tpl с использованием Terraform интерполяции (%{ for ... }). Шаблон разбит на 3 группы: webservers, databases, storage.
* В файле ansible.tf сделан ресурс local_file.hosts_cfg. Функция templatefile видит три типа структур, массив хостов count webservers, преобразованную функцией values() карту for_each (databases) и одиночную машину storage.
* Для каждой ВМ вызвана и добавлена в инвентарь переменная .fqdn, взятая из провайдера Yandex Cloud.
