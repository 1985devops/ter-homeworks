# Решение 3

* С помощью команды terraform state list выведен полный список отслеживаемых ресурсов инфраструктуры.
* terraform state rm состояние проекта очищено от модулей сети vpc_dev и виртуальных машин marketing_vm, analytics_vm. Cами ресурсы остались работать в Yandex Cloud.
* Ресурсы успешно импортировались обратно в конфигурацию Terraform с помощью команд terraform import.
* terraform plan подтвердил отсутствие критических расхождений конфигурации и успешное восстановление стейта проекта.
